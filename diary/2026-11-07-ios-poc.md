# T3 Code Exact iOS POC

## Rough

Port the first useful T3 Code mobile loop to Exact2 for iOS. The loop opens the home thread list, manages environments, opens a thread, and sends a local message.

## Lean in

Use Exact navigation routes and native iOS presentation. Seed deterministic environments, projects, threads, and transcript messages so the POC can be compared without a server connection.

## Needed

Home must show the T3 Code header, environment filter, thread rows, and a new thread action. Environments must show connected rows with status and enable controls. Thread details must show the project context, transcript, and composer.

## Checkpoints

- Cloned `pingdotgg/t3code` into the requested checkout.
- Scaffolded an Exact2 app under `exact-ios-app` using the local `exact2-origin-main` checkout.

## 2026-11-10: native chrome and Duo split

### Rough

The headers were hand-drawn, a placeholder header "T3 Code Exact iOS" showed, and header buttons did not move to the Duo rail.

### Lean in

Let UIKit own the chrome. Each route's first child is its `header`, so the bar, Back, bar items, menus and search are native. A device probe in the Swift module reports the hinge, the vertical bar edge and whether a split fits.

### Needed

- Folded Duo and phone: one stack per tab. The system tab bar shows only where a rail exists; a phone keeps the floating tab bar view.
- Unfolded Duo: `tabContainer` pairs each list tab with a detail tab in a `UISplitViewController`. A gated task moves an open thread between the two stacks when the pose changes.

### Checkpoints

- The root `navigate` handler must `go`, not `push`: a system Back sends the location beneath, and `push` made Back loop.
- A tab's routes are built when the router first selects the tab. The split selects the detail tab through the regroup task so its root exists.
- `UISplitViewController` kept its automatic primary width until minimum, maximum and preferred width agreed.
- Leading bar items need `axisBehavior = .horizontalOnly` to stay in their column instead of the rail.
- An absolutely placed box in the split's detail column is not inset for the rail; the composer subtracts `env(safe-area-inset-right)` there.
- The app connects to a real T3 server and sends real messages; the seeded-data plan in the first section no longer applies.
