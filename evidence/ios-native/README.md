# Native iOS evidence

Captured November 27, 2026 from the integrated `T3 Code Exact iOS` app on a local iPhone simulator running iOS 27.2 at 3× device pixel density.

These captures prove the native shell and current iOS layout: Home, Settings, Usage limit cards, and Pull Requests filters. The deterministic PR/thread-data journeys are currently marked web-only by the app contract, and the local fixture does not expose those datasets to native, so these images do not claim feature-data parity or native animation parity.
